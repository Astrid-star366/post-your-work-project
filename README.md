# US Bikeshare Data Explorer

An interactive Python script that explores US bike share data. It calculates
statistics on travel times, popular stations, trip durations and user types.

## Information about how to use your project

Requirements: Python 3 with the libraries pandas and numpy.

Run the script in the terminal:

```
python bikeshare.py
```

Then follow the prompts to choose a city, month and day.
## Files used

- `bikeshare.py` - Python script for the data analysis
- `new_york_city.csv` - bike share data (not tracked, listed in `.gitignore`)
